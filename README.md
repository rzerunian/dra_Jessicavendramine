# Site da Dra. Jéssica Vendramine

Pacote estático pronto para visualização local ou publicação.

## Abrir localmente

Abra `index.html` diretamente no navegador ou, no VS Code, use uma extensão de servidor local como **Live Server**.

## Publicar

Envie todo o conteúdo desta pasta para a raiz do serviço de hospedagem, preservando a estrutura de diretórios.

## Arquivos principais

- `index.html`: página principal.
- `assets/jessica-site.css`: estilos e animações.
- `assets/jessica-site.js`: interações do site.
- `assets/raw_files/dra-jessica-vendramine.jpg`: imagem profissional.
- `politica-de-privacidade.html`: política de privacidade.
- `politica-de-cookies.html`: política de cookies.
- `termos-de-uso.html`: termos de uso.

O site não requer instalação, compilação ou dependências via npm.
